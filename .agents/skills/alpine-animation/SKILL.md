# Alpine animation

Run from the repository root, three directories above this skill. Read
[Animation](../../../docs/ANIMATION.md) for the current pipeline, action targets
and retained findings. Identify the user's action, phase, body/equipment chain
and visible defect before selecting a route.

| Need | Load |
|---|---|
| Locate the owning stage or interpret rig data | [Rig and actions](references/rig-and-actions.md) |
| Diagnose, author and grade a change | [Review loop](references/review-loop.md) |
| Capture, render, compare or seal evidence | [Tool recipes](references/tool-recipes.md) |
| Transfer results or unfinished work | [Handoff](references/handoff.md) |

Verify live source/engine identity; capture the baseline before editing. Preserve
unsaved authoring sessions. Source retargeting belongs in assets; runtime blends,
targets and fitting belong in presentation. Keep one final skeleton writer,
connected anatomy, rigid boots/equipment and fixed grips. A cosmetic correction
does not authorize solver changes.

Use action-specific targets: tuck narrowing is not a carving, flight or landing
constraint. Inspect final poses through entry, hold and release with matched
inputs, physics and cameras. Separate mechanical checks, visual grading and user
acceptance. Historical grades and sealed packages do not establish acceptance of
a new revision. Detailed run output belongs in artifacts; update the owning guide
with durable findings.
