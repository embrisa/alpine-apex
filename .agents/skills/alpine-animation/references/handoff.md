# Animation handoff

Keep durable decisions in [Animation](../../../../docs/ANIMATION.md), detailed
results with the revision. Include:

- User's visible intent, action/phase and constraints; owning source changes.
- Before/after revision IDs, source/asset/engine hashes, frozen snapshots and
  exact commands/inputs/scenarios. State absent or mismatched baseline coverage.
- Chronological media, camera metadata, selected frame IDs/reasons, requested vs
  final measurements, actual clothing-audit scope and regression receipts.
- Worst remaining defect and known cause; compare new failures with baseline.
- Separate automated, rendered, performance and user acceptance. For grading,
  include reviewer/evidence/status/score/comment per requested action and chain;
  distinguish unrated, unjudgeable and zero. Keep user/model records separate.
- Adopted/rejected/experimental disposition, missing evidence and the bounded
  next action. Sealed, mechanically passing or author-scored does not mean accepted.
